# 🚀 CrackIt – AI Interview Preparation Platform

CrackIt is an AI-powered web application that helps students prepare for placements through mock interviews, resume analysis, and truth detection using AI.

---

## ✨ Features
- 🤖 AI Mock Interview System
- 📄 Resume Analyzer
- 🔍 Resume Truth Detector
- 📊 Performance Feedback
- 🎯 Placement Preparation Assistant

---

## 🛠️ Tech Stack
- Django (Backend)
- Python
- AI APIs (Gemini / NLP Models)
- HTML, CSS, JavaScript (Frontend)

---

## 📂 Project Structure
- Backend: Django Framework
- AI Engine: Interview + Resume Analysis Logic
- Frontend: UI for interaction

---

```bash
git clone https://github.com/ankit1947sah/CrackIt-interview-with-AI.git
